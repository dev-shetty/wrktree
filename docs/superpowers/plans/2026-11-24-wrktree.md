# wrktree Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `wrktree`, a Go CLI with an interactive screen and subcommands that lists, switches, opens, deletes, and prunes the git worktrees of one repository.

**Architecture:** `internal/git` and `internal/disk` run `git` and `du` and parse the output. `internal/status` joins the values into rows. `internal/cmd` (Cobra) and `internal/ui` (Bubble Tea) call the same functions. Switch works through a shell function that reads a path from the file in `WRKTREE_CD_FILE`.

**Tech Stack:** Go (installed version), `github.com/spf13/cobra`, `github.com/charmbracelet/bubbletea` (v1 line), `github.com/charmbracelet/lipgloss` (v1 line), `github.com/BurntSushi/toml`, `golang.org/x/term`.

**Spec:** `docs/superpowers/specs/2026-11-24-wrktree-design.md`

## Global Constraints

- Module path: `github.com/dev-shetty/wrktree`. Binary name: `wrktree`.
- macOS and Linux only. zsh and bash only.
- **Do not run destructive commands on real repositories.** `git worktree remove`, `git worktree prune`, and `git branch -d` run only in repositories that `internal/testrepo` creates below `t.TempDir()`. Manual checks of delete and prune use a repository in the scratchpad directory.
- **Do not publish.** No `git push`, no `gh repo create`, no release. Local `git init` and local commits only.
- Each test that runs `git` uses `internal/testrepo`. No test reads or writes the real home directory. Tests set `XDG_CONFIG_HOME` and `XDG_CACHE_HOME` to temporary directories.
- The tool needs no configuration file to operate.
- All git calls use porcelain output and `git -C <path>`.
- The screen draws on stderr. Stdout carries only data (the `ls` table, the switch path).
- Error text for no repository: `wrktree: not a git repository`, exit code 1.
- Defaults: `open = "code -n {path}"`, `base = ""`, `fetch = true`, `size_ttl = "24h"`. Fetch timeout: 15 seconds. `du` limit: 4 processes at one time.

## Review Focus

1. **Path with a space or a quote** (`/tmp/my repo/it's`): the open command and the cd file must carry the exact path. Test in Task 5.
2. **Worktree folder deleted by hand** (prunable entry): the row shows, its cells show `—`, no command crashes, and delete says `folder is missing: use prune`. Tests in Tasks 3 and 6.
3. **Repository with no `origin` remote**: the distance column shows `—`, the fetch does not run, and no command exits with an error. Tests in Tasks 2 and 6.
4. **Current directory is a subdirectory or a symlinked path** (macOS `/tmp` → `/private/tmp`): the tool still marks the correct current worktree. Test in Task 2.
5. **Narrow terminal** (40 columns): no line of the screen is wider than the terminal, and long branch names end with `…`. Test in Task 8.

// internal/status
type Row struct {
    WT          git.Worktree
    Current     bool
    Changed     int;  ChangedOK bool
    Ahead, Behind int; DistOK bool
    LastCommit  time.Time; CommitOK bool
    Size        int64; SizeState disk.State
}
type Options struct { Base string; TTL time.Duration; Fresh bool; Cwd string; Now time.Time }
func LoadAll(ctx context.Context, r git.Runner, wts []git.Worktree, cache *disk.Cache, repo string, o Options) []Row
func Sort(rows []Row)                                   // main first, then LastCommit, newest first
func Table(w io.Writer, rows []Row, base string, now time.Time)
func JSON(w io.Writer, rows []Row, base string) error
func Age(t, now time.Time) string                       // "2 hours ago", "3 weeks ago", "1 day ago"

// internal/cmd
type Env struct {
    Dir string; Stdin io.Reader; Stdout, Stderr io.Writer
    IsTerminal func() bool                 // stdin and stderr are terminals
    RunOpen func(template, path string) error
    Now func() time.Time
}
func New(env Env) *cobra.Command
func Execute() int // real Env. Prints "wrktree: <error>" to stderr. Returns 0 or 1.
```

`LoadAll` waits for all values, `du` included where `disk.Decide` says so, then writes and saves the cache. A value that fails keeps its `OK` flag false. `Options.Base == ""` means no base: `DistOK` stays false.

Table cells: `clean` or `N files` (`1 file`); `↑A ↓B`; `—` for a value that is not available; size `~1.4 GB` for `SizeCached`, `1.4 GB` for `SizeFresh`. The current row starts with `●`. A locked row has ` [locked]` after the branch. A prunable row has ` [missing]`. A detached row shows the first 7 characters of `Head`. If the folder base name differs from the branch, add ` (folder)`. The header of the distance column is the base name, or `BASE` with no base.

JSON fields for each row: `path`, `branch`, `head`, `main`, `current`, `detached`, `locked`, `prunable`, `changed` (number or null), `ahead`, `behind` (number or null), `base`, `last_commit` (RFC 3339 or null), `size_bytes` (number or null), `size_approx` (bool).

Command rules:
- Each command opens the repository from `env.Dir`. On `git.ErrNotRepo`, the error is `not a git repository`.
- `ls [--json] [--fetch] [--fresh]`: `--fetch` runs `FetchBase` with a 15 second timeout first. A fetch failure prints `wrktree: fetch failed: distances can be stale` to stderr and continues.
- `switch <name>`: `git.Match`, then `shell.WriteCD`.

### Task 7: The commands `rm` and `prune`

**Files:**
- Create: `internal/cmd/rm.go`, `internal/cmd/prune.go`
- Modify: `internal/git/remove.go` (add `DeletePrompt`)
- Test: `internal/cmd/rm_test.go`

**Interfaces:**
- Consumes: `git.PlanDelete`, `Remove`, `DeleteBranch`, `PruneDryRun`, `Prune`, `git.Current`, `cmd.Env`, `disk.Cache`.
- Produces: subcommands `rm <name> [--force] [--branch]` and `prune [--yes]`.

`rm` flow, in this order:
1. `git.Match`. Then `PlanDelete`. If `Blocked != ""`, the error is the blocked text.
2. If the worktree is the current one, the error is `cannot delete the worktree of the current directory`.
3. With `--force`: no prompt.
4. Else if `NeedsYes`: if `!env.IsTerminal()`, the error is `worktree has changes: use --force`. Else print the prompt to stderr and read one line. Only `yes` continues.
5. Else: print the prompt, read one line. `y` or `yes` continues (case ignored).
6. An answer that does not continue prints `cancelled` to stderr and exits 0 with no change.
7. `Remove(path, force)` where force is `--force || NeedsYes`. Then delete the cache entry and save the cache.
8. With `--branch` and a branch name: `DeleteBranch`. On failure, the worktree stays deleted, and the error carries the git message.
9. Print `deleted <path>` to stdout.

Prompt texts, exact:
- Clean: `Delete worktree <branch> at <path>? Ignored files are deleted too. [y/N] `
- Changes: `<branch> has N changed files. They will be lost. Ignored files are deleted too. Type yes to delete: `
- Detached commits: `<head7> has N commits that no branch contains. They will be lost. Ignored files are deleted too. Type yes to delete: `
- The two together: use the first sentence of each, then the common end.

`prune` flow: `PruneDryRun`. With no lines, print `nothing to prune` and exit 0. Else print the lines, then the prompt `Prune N entries? [y/N] ` unless `--yes`. Then `Prune` and print `pruned N entries`.

type Deps struct {
    Git   git.Runner
    Cfg   config.Config
    Cache *disk.Cache
    Repo  string        // cache key and title
    Name  string        // RepoName
    Cwd   string

```

Messages (package-private): `worktreesMsg{wts []git.Worktree; base string; err error}`, `changedMsg{path string; n int; err error}`, `distMsg{path string; ahead, behind int; err error}`, `commitMsg{path string; t time.Time; err error}`, `sizeMsg{path string; bytes int64; err error}`, `fetchMsg{err error}`.

Behavior:
- `Init` loads the worktree list and the base. On `worktreesMsg`, the model makes the rows, applies `disk.Decide` to each, and starts one command for each value. If `cfg.Fetch` is true and a base exists, it also starts the fetch with a 15 second timeout.
- Until `fetchMsg` arrives, distances draw dimmed. On `fetchMsg` with no error, the model starts the distance commands again. On an error, the footer shows `fetch failed: distances can be stale`.
- `sizeMsg` writes the cache and saves it. `SizeStale` draws dimmed with `~`. `SizeNone` draws `…`.
- A limit of 4 size commands run at one time. The others wait in a queue in the model.
- Keys in list mode: `↑`/`k`, `↓`/`j`, `enter` (set `SwitchPath`, quit), `o` (set `OpenPath`, quit), `f` (fetch again), `r` (run all values again, sizes with fresh=true), `/` (filter mode), `q`/`esc`/`ctrl+c` (quit). `d` and `p` come in Task 9.
- Filter mode: typed text filters rows by substring of branch or folder name, case ignored. `enter` keeps the filter and returns to list mode. `esc` clears it.
- `enter` and `o` on a prunable row do nothing and show `folder is missing: use prune` in the footer.
- Title line: ` wrktree · <Name>` on the left, `<N> worktrees · <total size>` on the right. The total has `~` if a size is cached or stale. The total omits rows with no size.
- `View` never returns a line wider than the terminal width from `tea.WindowSizeMsg`. The branch column shrinks first and ends with `…`. Below 60 columns, hide the LAST COMMIT column. Below 45 columns, also hide SIZE.
- Footer: ` enter switch · o open · d delete · p prune · f fetch · / filter · q quit`. Cut it at the width.

**Interfaces:**
- Consumes: `git.PlanDelete`, `git.DeletePrompt`, `Remove`, `DeleteBranch`, `PruneDryRun`, `Prune`, `ui.Model`, `shell.WriteCD`, `env.RunOpen`.
- Produces: messages `planMsg{wt git.Worktree; plan git.DeletePlan; err error}`, `removedMsg{path string; err, branchErr error}`, `pruneListMsg{lines []string; err error}`, `prunedMsg{n int; err error}`.

Delete in the screen:
- `d` runs `PlanDelete` for the row. If `Blocked != ""`, the footer shows the text.
- If the row is the current worktree and (`!CanCD` or no main worktree exists), the footer shows `cannot delete the current worktree: run through the wt function`.
- Else the prompt replaces the footer. It shows `git.DeletePrompt` text adapted to keys: clean → `y` deletes, all other keys cancel. `NeedsYes` → a text input, `yes` + `enter` deletes, `esc` cancels.
- In the prompt, `b` toggles `[x] also delete the branch` (clean prompt only: in the typed prompt, `tab` toggles it). Not shown for a detached worktree.
- After `removedMsg` with no error: remove the row, delete the cache entry, save the cache. If the row was the current worktree, set `SwitchPath` to the main worktree path and quit. `branchErr` shows in the footer and does not undo the delete.

Prune in the screen: `p` runs `PruneDryRun`. No lines → footer `nothing to prune`. Else show the lines and `Prune N entries? y/N`. `y` runs `Prune`, then loads the worktree list again.

Root command with no subcommand:
- If `!env.IsTerminal()`, run `ls`.
- Else run the program with `tea.WithOutput(os.Stderr)` and `tea.WithAltScreen()`. After it quits: `SwitchPath` → `shell.WriteCD`. `OpenPath` → `env.RunOpen(cfg.Open, path)`.
